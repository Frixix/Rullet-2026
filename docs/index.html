Principios Cuantitativos del Co-Piloto

  • El Filtro de Freno descarta el 85-90% de las tiradas para proteger contra el margen de la casa.
  • Las entradas se calculan solo cuando la desviación estándar supera el umbral estadístico (Z ≥ 2.0σ).
  • El Cero (0) actúa como disyuntor de simetría: cada cero absorbe apuestas de suertes simples.
